# Rebuild notice

When the desktop app tells the user a Rebuild is needed or recommended, after Steven forgot to rebuild following the 0.1.1 update (PR #29, on top of #28, where Start downloads the images an app update replaced).

- **The app remembers what each image was made from.** `images.json` in the stack folder records, for each local image name, the image ID the app last pulled or built under it and its source: what its published tag names (`<PACKETVER>-<mode>-<commit>-<hash>` for rAthena, `<hash>` for the portal), whether or not it was published. An image pulled before the app kept records is read from the published tag it still carries. A locally built image from before then is unknown, and the app says nothing about it.
- **The notice shows only what Start won't fix.** When a newer published image exists, Start downloads it (#28), so there's nothing to tell, and the bar stays hidden until a Start has tried (Steven, 2026-10-14). The bar shows when the image here is out of date and either nothing is published for it (another PACKETVER, a fork, `PREBUILT_IMAGES=` empty) or its download failed. Rebuild then builds it locally.
- **Needed or recommended.** "Rebuild needed" when the game server was built for other build settings or another rAthena commit than `.env` names, which happens when saving a build setting is followed by a failed or cancelled rebuild, or `.env` is edited by hand. "Rebuild recommended" when only the app's build files (`docker/rathena/`, `portal/`) changed, since the old image still runs.
- **One bar at a time.** Above every screen, in the order things get done: Server update available, then the Rebuild bar, then Restart on the new version. A server update rebuilds everything anyway, so the Rebuild bar waits behind it.
- **A new portal gets its own restart.** After a Rebuild that changed only the portal, the restart bar says so and offers **Restart the portal**. It does the same full `up` as Restart on the new version, which only recreates containers whose image changed, so nobody in game is disconnected.
- **The mods screen keeps its own Rebuild warning** for a server built before mods existed: that's read from the map server's log, not from the image records.
- **Start never rebuilds on its own.** A local build takes 5 to 10 minutes, so the bar offers the Rebuild and the user clicks it (Steven, 2026-10-14).
