# rAthena's custom NPCs

Roadmap feature 20: switch on the custom NPCs rAthena ships under `npc/custom/`, which its `npc/scripts_custom.conf` lists commented out. Asked for by Steven on 2026-10-15.

- **On the Mods screen, below the mods.** They're server-side custom content like mods, apply on the same restart, and share its "Restart game servers" and Rebuild notices, so they don't get a screen of their own.
- **A list compiled into the app, not read from the image.** `desktop/src-tauri/custom-npcs.json` names each NPC, groups it as `scripts_custom.conf` does (Basic, Other, Quests, Events, Battlegrounds), and says in a sentence what it does, which the scripts' own headers don't say well. Scripts that only work together, such as the Treasure Hunters Guild's five, are one entry. Entries carry a warning where `scripts_custom.conf` or the script gives one (godly items, Old Blue Box prizes, a GM has to open the stock market, floating rates replace the Battle config rates).
- **Choices go in `overrides/custom_npcs.txt`.** One script path per line, read by `entrypoint.sh` on every start into `npc/custom_npcs.conf`, which `npc/scripts_custom.conf` imports before the mods' `npc/mods.conf`. Lines the screen doesn't know are kept, so other `npc/` scripts can be added by hand. Only paths under `npc/` ending `.txt`, with plain characters, are loaded; anything else, or a script the image doesn't have, is skipped with a `[Warning]` naming the file, which the screen shows under that NPC.
- **Mode-only scripts are written `re: <path>` or `pre-re: <path>`.** They stay switched on across a mode switch but only load in their mode; the screen says so. Only the Geffen Magic Tournament needs it: its instance and quest are only in Renewal's databases. rAthena's `npc/re/custom/lasagna/` already loads in Renewal, so it isn't listed.
- **Two scripts are listed but can't be switched on.** The Card Seller and Hunting Missions read rAthena's item and monster databases from SQL tables (`item_db`, `mob_db`), which this stack never creates or fills (the server reads the YAML files). The screen says why instead of loading a script that fails.
- **The unofficial battlegrounds aren't listed.** `scripts_custom.conf` names `npc/custom/battleground/unofficial/*`, but those files aren't in rAthena any more.
- **Pending and Rebuild work as for mods.** The stack folder's `.custom-npcs-applied` records what the server loaded at its last start from the app; a difference shows "loads on restart" or "unloads on restart". `entrypoint.sh` prints `Custom NPCs on:` on every start, and an image without that line asks for a Rebuild.
- **Errors come from the map server's log.** rAthena's errors and warnings that name one of an NPC's scripts, including the `[Debug]` lines that say which script a failing command ran in, show under it.
- **Checked on a real build.** Every listed script loaded with the rest of rAthena in both modes, at the pinned commit (b6f89ab), with no errors except the Card Seller's missing SQL table. CI's stack smoke tests switch on every NPC the app offers, the way the screen writes them, and fail if one doesn't load or logs an error, so a new rAthena commit that drops or breaks one shows up there.
