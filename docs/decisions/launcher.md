# The launcher

Our patcher (`portal/cmd/patcher`, [own-patcher.md](own-patcher.md)) becomes a tabbed launcher in the portal's look. Asked for by Steven on 2026-10-23: get the players' launcher away from Internet Explorer (rpatchur's window), with more features, tabs and the portal's theme ([portal-redesign.md](portal-redesign.md)).

- **It's our patcher, grown.** Same exe name (`rag-wrapper-patcher.exe`), same config, cache and signed `info.json`, same self-update, so players who have the new patcher get the launcher with their next start, without a download. Patching itself didn't change.
- **Gio draws the window** ([gioui.org](https://gioui.org), pure Go, no cgo, cross-compiled like before). Steven picked it over WebView2 (needs Edge's runtime, works badly under Wine) and themed Win32 controls (old look, everything hand-drawn). It draws with Direct3D 11 or OpenGL, which any PC that runs the game has.
- **Gio stays at v0.8.0.** Gio v0.9 and later read the mouse only through `WM_POINTER` messages and call `RegisterTouchWindow` / `EnableMouseInPointer`, which Wine 9 doesn't implement, so the window never opens there (Wine's development versions have them). v0.8.0 opens, draws and takes clicks under Wine 9. It needs `github.com/go-text/typesetting` v0.2.1; with a newer one every letter draws as a box. Check a newer Gio under Wine 9 before moving either.
- **The portal's look.** Its colour tokens (light and dark), Nunito, raised panels with a blue title bar and three window dots, pink Play button, blue tabs, the poring logo drawn from `poring.svg`. Nunito is the portal's variable font cut into 400, 700 and 800 TTFs (`cmd/patcher/fonts/`; Gio can't read WOFF2), with its OFL licence.
- **Four tabs.** Play: the server at a glance (game server up, playing now, mode, client date), the newest news post and buttons for the portal's pages. News: every post. Players: who's online (name, job, levels, map) and the top adventurers. Settings: the client's settings program, Check game files, the game and screenshot folders, Keep the launcher open after Play, and the theme. Status, progress, Try again and Play sit under every tab.
- **The server at a glance comes from `/patcher/launcher.json`**, a new portal page: server name, mode, client date, address and login port, online count, up to 100 online and the top 10 characters (admins' left out, as on Rankings), the 10 newest news posts as plain text, and the portal's page links. It isn't signed and nothing in it changes the client; links that don't point at the portal are dropped. The launcher fetches it at start and every 30 seconds.
- **"Game server" means the login server answers from this PC.** The launcher opens a TCP connection to the address and login port the client uses, so it says Offline when the game would fail to connect, even if the portal answers.
- **Check game files rebuilds `rag-wrapper.grf` from scratch.** It deletes that GRF, sets the last applied patch to 0 and patches again, so every patch applies in order. It asks first, since it downloads everything again. `data.grf` and other files are left alone.
- **Settings live in `rag-wrapper-launcher.json`** beside the exe: keep open after Play, theme (Match Windows, Light, Dark; Match Windows reads `AppsUseLightTheme`), the last tab and the server's name (shown until the server answers). Patches can't overwrite it.
- **Errors show in the window, not in boxes.** A failed Play, Settings or folder button says why on the status line. Only the checks before the window opens (missing config, no `data.grf`) still use message boxes.
- **Licences.** The image collects Gio's, go-text's, `golang.org/x/*`'s and Nunito's licences into `LICENSE-third-party`, which goes in the download as `licenses/third-party-LICENSES.txt` beside Go's.
- **rpatchur stays the main download for now**, as decided for the new patcher: the How to connect page offers this as "the new launcher" until a player's Windows PC confirms it.
- **Checked under Wine 9** (Xvfb, llvmpipe): every tab in light and dark, patching four test patches with progress, Try again after the portal was down, Check game files, Play starting the client and closing the launcher, and self-update.
