# AppImage

Packaging the desktop app as an AppImage (roadmap feature 9, first half; prebuilt server images come later).

- **The app ships as one AppImage, and nothing else.** `tauri.conf.json` builds only the `appimage` target; the `.deb` target is gone, as the roadmap decided (no .deb or Flatpak). The rAthena image is still built locally on first start, as before.
- **GitHub Actions builds the releases.** Pushing a tag like `v0.2.0` runs the Release workflow, which checks the tag matches the version in `tauri.conf.json`, builds `rag-wrapper-<version>-x86_64.AppImage` and publishes it as a GitHub release, with the pinned rAthena commit and the requirements in the notes and GitHub's list of merged PRs below. It's published straight away, not kept as a draft: pushing the tag is already the deliberate step, and Steven is the only one installing it.
- **It's built on Ubuntu 22.04.** An AppImage needs a glibc at least as new as the one it was built with, so building on the oldest supported runner lets it run on older distributions as well as Steven's.
- **Pull requests that touch the packaging build it too.** A change to the workflow, `tauri.conf.json`, `Cargo.toml` or `Cargo.lock` builds the AppImage, checks it holds the stack files, and keeps it as a workflow artifact for 14 days. It isn't a required check, so its job name can change; the required "Desktop app (Rust)" job still runs the compile checks and tests on every PR.
- **Programs the app starts don't see the AppImage's libraries.** The AppImage's launcher sets `LD_LIBRARY_PATH`, `XDG_DATA_DIRS`, GTK's module paths and more to point inside it; a browser or file manager started with them can load the wrong GTK and fail. `src/host.rs` takes those entries out for `docker` and for `xdg-open` (opening folders and web pages), so they get the user's own environment. This replaced Tauri's opener plugin, which passes the environment on unchanged.
- **The user needs Docker with the Compose plugin, and FUSE 2.** The AppImage doesn't carry Docker. FUSE 2 is `libfuse2` (`libfuse2t64` on Ubuntu 24.04); without it, `--appimage-extract-and-run` works.
