# What's new for players

Roadmap feature 22: after an app update, the desktop app offers a "What's new" post for the account portal's News page, written from the release notes. Built in the PR that adds this file; the post goes through the News screen ([news-editor.md](news-editor.md)).

- **A "For players" section in the release notes**, not the whole notes file. The notes are written for the person running the server (Settings fields, PR links, commit ids), and there's no sensible way to turn those into player news automatically. The section is written with the rest of the notes, in the release PR, and also shows on the GitHub release, so it's clear what players were told. A version without the section offers no post.
- **The app bundles every version's notes when it's built** (`build.rs` reads `docs/releases/*.md`), so it knows the lines of versions it skipped. Updating from 0.7.0 straight to 0.9.0 drafts one post with 0.9.0's lines and then 0.8.0's.
- **A bar, not a pop-up or an automatic post.** "Tell players what's new" sits with the other bars above every screen. **Write the post** opens the News screen with a new post on top: the title "What's new", today's date in italics like any new post, then the lines. Nothing reaches players until **Save**, so the draft can be edited or deleted first.
- **It waits until the update is live.** The bar shows only when no server update, rebuild or restart is waiting, so the post doesn't tell players about emotes before the server has them. It's hidden on the News screen, where the draft is being written. Steven chose this over offering it straight after the app update (review, 2026-10-16).
- **Offered once per app version.** Saving the News with the draft in it, or **Not this time**, records the version in `.env` (`PLAYER_NEWS_OFFERED`). Deleting the draft, Reload, or closing the app before saving keeps the offer. A new install records its own version at setup, so it isn't offered a post about changes its players never saw. An install updated from a version before this feature has nothing recorded, so only the current version's lines are offered.
- **The release PR writes the "For players" lines**, with the rest of the notes, from the PRs merged since the last version, rather than each feature PR adding its own line to a shared file that every PR would edit (review, 2026-10-16).
