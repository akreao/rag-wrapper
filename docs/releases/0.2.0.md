## New
- Each game mode has its own characters. Accounts are shared, but Pre-Renewal and Renewal keep their characters, storage and cash points in separate databases, so switching modes swaps the characters and switching back brings the old ones back (#30).
- The client-files folder has `Pre-Renewal/` and `Renewal/` folders for files that differ by mode, such as your translation additions. A patch carries the shared files plus the server's current mode's folder, and the Client patch screen says when the server's mode differs from the latest patch, so publishing after a switch swaps the players' files (#31).
- Start checks the server's ports first. When something else holds one, it names it: another Docker container, with the command to stop it, or another program, with the command that shows which (#27).
- The portal's port can be changed on the Dashboard's Connecting card. Only the portal restarts (#27).
- A bar above every screen says when a Rebuild is needed or recommended because Start can't download a newer image (#29).
- A mod's `db/barters.yml` now loads, and its clashes are checked like the other databases. `mods/README.md` explains how a mod replaces one of rAthena's NPCs (#33).

## Changed
- Two mods adding the same drop to a monster give it once, from the later mod, instead of twice. A different rate for the same drop is listed as a clash (#26).
- The Mods screen shows clashes as soon as the enabled mods, their order or their files change, without restarting the server (#26).
- The How to connect page tells players to install the matching translation from WARPGATE's LANG tab when the server switches between Pre-Renewal and Renewal (#30).
- Backups and restores cover the accounts database and both modes' characters databases (#30).

## Fixed
- After an app update, Start kept running the old server and portal images until a Rebuild. It now downloads the images the update replaced (#28).

## Before you update
- Make a backup first. On the first start, the characters already on the server move into the current mode's database. The other mode starts with no characters the first time you switch to it.
- No Rebuild needed: Start downloads the new server and portal images. If the new bar says a Rebuild is needed (for example, you build images locally), click Rebuild.
- If your client-files folder has translation additions for one mode only, move them into its `Pre-Renewal/` or `Renewal/` folder and publish a patch.
