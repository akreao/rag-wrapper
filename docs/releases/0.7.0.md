## Server
- rAthena moved from 15a8dc8 to 266a587, which brings in two upstream changes that rAthena hasn't merged yet (#60):
  - The client's emote window works, including the cash emotion packs. Packs are locked until bought with Nyangvine Fruit; admin accounts get every pack. Setting `emotion_cash_check` to `no` in the Battle config window unlocks them for everyone. Emotes use the newer emotion packet the 2025 client expects.
  - The stylist accepts the newer client's purchases, and in Renewal it offers job outfits.
- The app offers it as a server update; your database is backed up first. There's no database change.

## Before you update
- After updating the app, click **Update server** on the bar, then **Restart on the new version** when players can be disconnected.
- Both changes are new upstream code, so ask players to try emotes, the cash emote window and the stylist, and tell you if anything misbehaves. If they do, the server can go back to 15a8dc8.
