## Changed
- Mods that change the same database entry now combine their changes. A monster gets both mods' drops, and two mods setting an item's `Jobs` get both lists. Where two mods set the same value differently, the later mod wins and the Mods screen lists the clash under both mods (#24).
- Players no longer get rAthena's PIN code window before character select. They log in with their portal password only (#23).
- The How to connect page sends players to WARPGATE's LANG tab for the English translation, matching the server's Pre-Renewal or Renewal mode. It no longer offers `sclientinfo.xml` (#21).
- The client patcher has a Settings button that opens the client's `opensetup.exe` (#22).

## Fixed
- The client patcher didn't check for patches when it opened, hung on "Checking for updates..." after Try again, and Exit and Play did nothing (#22).
- A patcher zip downloaded on the server PC pointed players' patchers at `localhost`. It now uses the server's LAN address (#22).

## Before you update
- Players who already downloaded the patcher zip need to download it again from the How to connect page.
- Click Rebuild once after updating. Start keeps the server and portal images already on the machine, and this version changes both.
