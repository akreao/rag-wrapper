## New
- Settings has a Server version card with a **Go back** button that returns the server to the rAthena version it ran before, backing up the database first, the same way a server update does. Going back again returns to the newer one (#64).
- After an app update, once the server runs the new version, a bar offers a "What's new" News post for players, drafted from these notes. Nothing reaches players until you save it (#63).
- The How to connect page has a "Playing on Linux" section, with a launcher script that sets up Wine with DXVK and starts the new patcher (#62).
- Client patches and the new patcher's self-updates are signed. The new patcher only applies patches and updates this server published. The app makes the signing key for you (#69).
- A "This network only" switch on the Connecting card makes the server listen only on the address players connect to, so it isn't reachable from other networks the computer joins, such as public Wi-Fi. It's off by default (#67, #73).

## Changed
- The item log no longer records player drops and pickups, monster loot or used items, which filled the database (#67).
- The server's container logs are capped at 30 MB each (#67).
- Only one copy of the desktop app runs at a time (#68).
- Backups are readable only by your user account (#68).

## Fixed
- Downloads from the portal (the patcher, its zip and patches) were cut off after 30 seconds, so slow connections never finished them (#66).
- The desktop app could freeze while Docker was slow, and could lose a setting when two changes were saved at once (#68).
- A failed database upgrade now stops the server with the file's name, instead of failing differently on every later start (#67).
- After a mode switch whose rebuild failed, the server could start one mode's build on the other mode's characters. It now refuses to start until you rebuild (#67).
- Log-in and sign-up limits on the portal could be bypassed with many requests at once (#66).

## Before you update
- No Rebuild needed: Start downloads the new server and portal images.
- Players with the new patcher don't need to download it again. It picks up the signing key the first time it runs after the update.

## For players
- Patcher downloads no longer stop partway on slow connections.
- The new patcher checks every patch and update came from this server before applying it.
- Playing on Linux: the How to connect page has a guide and a launcher script.
