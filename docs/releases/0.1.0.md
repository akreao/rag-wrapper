The first release of rag-wrapper as an AppImage: a desktop app that runs a private rAthena server, its database and an account portal in Docker, for the real Ragnarok Online client on your LAN or a private VPN.

- First-run setup creates the GM admin account; players register in the web portal.
- Start, stop, rebuild and server updates, with the server images downloaded prebuilt where one matches (otherwise built locally).
- Settings for rates, drops, the server name and message of the day, the client date (2025-07-16 or 2022-04-06) and Pre-Renewal or Renewal.
- Dashboard of who's online and what the server uses; backups and restore; a mods folder; the address players connect to, including VPN addresses.
- Client patches published to players through the portal's patcher.
