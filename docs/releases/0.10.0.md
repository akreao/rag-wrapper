## New
- The desktop app has a new look: a sidebar for every screen, a header with a status pill and the one Start or Stop that applies (Rebuild, Restart server and Quit are in its ⋯ menu), and notices as cards a bell can tuck away (#91, #92, #95, #96).
  - Overview shows status, players online and the connect address as cards, the services as tiles beside the Activity log, and who's online now. The address picker, This network only and the portal port are in Settings > Network.
  - Settings is in tabs, with switches, and has a Theme choice (match the desktop, Light or Dark) in Settings > App.
  - The other screens have a toolbar of actions at the top, and their long explanations fold away. Below 1000 px the sidebar shrinks to icons.
- The portal has a new look, styled like the game's windows, with a light/dark switch. `/` is a home page with the server's status, the newest news post, who's online, the top five and a database search. Logging in opens it (#93, #94).
- The new patcher is now a launcher with Play, News, Players and Settings tabs, a game server status check and Check game files, in the portal's look. It's the main download on How to connect, with rpatchur kept as a "download the old patcher" link (#97, #98).
- Players can delete characters in game (#90).

## Changed
- The account page shows the birthdate code players type to delete a character, the sign-up page explains the format, and accounts without a birthdate get a warning, since the game then refuses every delete (#90).
- The header says "Partly running" and offers Start when the game servers are up but the portal, web server or database isn't (#98).

## Fixed
- The new patcher froze on "Connecting..." when the news was long enough to need a scroll bar (#89).

## Server
- rAthena moved from 266a587 to f068783 (akreao/rathena#9), so deleting a character accepts the birthdate as YYMMDD or YYYYMMDD. The app also sets `char_del_delay` to 0: the client asks to delete straight away, and the 24-hour delay refused every delete (#90).
- The app offers it as a server update; your database is backed up first. There's no database change.

## Before you update
- No Rebuild needed: Start downloads the new images, and the app then offers the rAthena move as a server update.
- Players with the new patcher get the launcher on its next start. Players on rpatchur can download the launcher from How to connect.

## For players
- You can delete characters in game. Type your birthdate as six digits (YYMMDD); your account page on the portal shows the exact code.
- The account portal has a new look, a home page with the server's status, news and who's online, and a light/dark switch.
- The new patcher is now a launcher with Play, News, Players and Settings tabs, and shows whether the game server is up. Download it from How to connect on the portal; if you already use the new patcher, it updates itself.
- The launcher fits small and scaled screens, shows names and news in any language, and tells you if your PC can't draw its window.
