## New
- Closing the window while the server runs keeps it running in a tray icon (Open, Start server, Stop server, Stop server and quit). Settings can start the server when you log in, with the window hidden. A Quit button in the header stops the server and exits (#78).
- Players in game are warned before a restart or stop: "Server restarting in 5 minutes", again at 1 minute and at the moment it happens. The header offers Go ahead now and Cancel while it counts down. The Dashboard has a Message everyone box (#79).
- An Events screen plans EXP and drop events, with a name, start and end, and rates as a percent of the server's own. The server switches the rates with no restart and announces each event in game. It can also add a News post (#82).
- The Dashboard has a chart of players online over the last day and week (#77).
- The portal has Items and Monsters pages. Players can search items and monsters and see stats, drops, who drops what and where monsters spawn, as the server is set up, including your mods and rates (#80).
- The portal has a Market page listing open vending shops and buying stores, with links to the items (#76).
- The Mods screen can install a mod from a zip, up to 1 GB. The mod is added switched off, and installing it again offers to replace it (#83, #87).
- The Dashboard warns when server passwords are still the example values, with a button to change INTER_PASSWORD. It also says when the first-run admin account already existed and wasn't changed (#81).

## Changed
- Closing the window no longer stops the server. Turn this off in Settings to get the old behaviour (#78).
- The daily backup is also made while the server runs. It waits until nobody is online, and runs anyway only when the last backup is two days old, warning players first because the game pauses during it (#78, #87).
- A server update, go-back or Rebuild keeps the current images until every new one is ready, so a failed or cancelled one leaves the server as it was (#81).
- The Linux launcher opens OpenSetup the first time a client folder is played from, and installs Microsoft's core fonts. A failed fonts install no longer stops the game, and `RO_FONTS=0` skips it (#75, #87).
- Local server builds pick their number of compile jobs by free memory. `MAKE_JOBS` in `.env` overrides it (#81).

## Fixed
- The new patcher no longer re-applies a GRF patch (growing the GRF each time) when it can't shrink the GRF afterwards, and it no longer holds whole files in memory (#81).
- The portal no longer builds a new patcher zip for every download (#81).
- The admin password stayed visible in the running game servers' settings after first start (#81).
- An old Docker Compose (before 2.24) failed with an unreadable error. The app now says to update it (#81).

## Before you update
- No Rebuild needed: Start downloads the new server and portal images.
- Players on Linux see OpenSetup once more the next time they play: pick the graphics card and save.

## For players
- Before a restart, the server warns you in game 5 minutes and 1 minute ahead.
- EXP and drop events: the server announces them in game when they start and end.
- The account portal has Items and Monsters pages: search any item or monster to see its stats, drops and where it spawns.
- The account portal has a Market page listing the shops that are open in game.
- The new patcher no longer makes the GRF grow on every run, and uses less memory.
- Playing on Linux: the launcher opens OpenSetup once per client folder, and a failed fonts download no longer stops the game.
