## New
- The portal has Online, Rankings and News pages, open to players without logging in. Online lists who's in the game. Rankings shows the top 50 by base level or zeny, for all classes or one, leaving out admins' and blocked accounts' characters. News is `overrides/portal/news.md` in the stack folder, written in Markdown with one `## ` section per post, newest first; the patcher's window shows the newest post (#47).
- Each backup has a Test button. It loads the backup into a throwaway database, checks every table, and shows its accounts, characters and items next to the live server's. Restoring a backup that failed its test asks you to confirm first (#48).
- A bar warns when the server starts on a different address or portal port from the last start, since players need to download the patcher again from the How to connect page. It has a button to copy the new link (#49).
- The Mods screen's New item mod button creates a mod with a sample potion, headgear and shop, carrying both the server's item entries and the client's item names, switched off for you to edit. The screen warns when a custom item has only one of the two halves. Custom items show your server's name instead of "ExampleRO" in game (#50).

## Before you update
- No Rebuild needed: Start downloads the new portal image.
- The first start after updating only records the server's address, so the address warning can show from the next change on.
