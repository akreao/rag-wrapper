## New
- Mods can carry client files in a `client/` folder, laid out like the game client's, with `Pre-Renewal/` and `Renewal/` folders for one mode's files. They go out with the next client patch, after the client files folder and in load order. Lua tables (`.lub`, `.lua`) are merged entry by entry, so a mod's file only needs its own quest or item entries; other files are replaced whole. Clashes show on the Client patch screen and under each mod on the Mods screen. A mod with only client files doesn't ask for a server restart (#44).

## Changed
- New characters all start on the main Izlude (Renewal) or the first training ground (Pre-Renewal), instead of one of rAthena's five copies picked at random, so new players can see each other. `overrides/char_conf.txt` can still set other start points (#42).

## Before you update
- Characters made before this keep their save point on whichever copy they were sent to. They can walk to the Channel Warp Official in Izlude ("Go to copy 1"), or an admin can use the portal's "Send to Prontera".
- No Rebuild needed: Start downloads the new server image.
