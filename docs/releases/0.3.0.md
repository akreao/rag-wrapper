## New
- A Battle config window, opened from Settings, lists every option in rAthena's `conf/battle` files with its comment, one file at a time or searched across all of them. Changed values are saved to `overrides/battle_conf.txt`, and options the map server turned down are marked with their allowed range and the value it used instead (#39).
- Players' clients save hotkeys and UI settings and load guild emblems from the server. The patcher zip and the How to connect page now include `ExternalSettings_kr.lub` pointing at the server; the English translation's copy pointed every player at their own PC (#40).
- Admin accounts show in yellow in game and get the client's GM features. `clientinfo.xml` lists them (#37).
- Mods can add rows to rAthena's text databases, such as `mob_skill_db.txt`, and the Mods screen lists them with the mod's other databases (#35).

## Changed
- Exp rates, drop rates and exp lost on death moved from Settings to the Battle config window, and are shown as rAthena stores them: percentages, 100 for official. Drop rates are set separately for normal, boss and MVP monsters. Values you set before are kept (#39).
- Commands on other players start with `*` instead of `#`, which the 2025-07-16 client keeps for itself. The Battle config window can pick another symbol (#36).

## Before you update
- Players need to download the patcher zip again from the How to connect page, or just `ExternalSettings_kr.lub`, and put it in `data\luafiles514\lua files\service_korea`. Reinstalling the translation in WARPGATE resets that file, so they download it again after one.
- Tell players to use `*` instead of `#` for commands on other players.
- No Rebuild needed: Start downloads the new server and portal images.
