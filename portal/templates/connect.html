How to connect

Play on this server with your own Ragnarok Online client. You need an account, two small files for the client, and a client that has been patched to use them.

This server only accepts players on the computer it runs on, because its address is {{.Address}}. To let other PCs on your network join, start it from the desktop app, which sets the computer's network address.

{{end}}

Steps

  1. Make an account. {{if $.Account}}You're logged in as {{$.Account.UserID}}, so this is done.{{else}}Create one here; the game uses the same username and password.{{end}}
  2. Use a client from the right date. The server is built for clients dated {{.ClientDate}}. {{if eq .PacketVer "20250716"}}Most players get this client from WARPGATE, which downloads it and keeps it up to date. {{end}}A client from another date may fail to log in or disconnect on the character screen. Ask whoever runs the server if yours doesn't match.
  3. Patch the client to read your own connection file. Unpatched clients from recent years, such as the 2025 and 2022 ones, ignore a custom clientinfo.xml and try the official servers. Patch the client's .exe with WARP, or another patcher that supports your client's date, and turn on at least Restore the use of clientinfo xml and Read data folder first. {{if eq .PacketVer "20250716"}}WARPGATE's WARP tab can install the patch set for this client for you. {{end}}The patcher's own guide explains how to load a client and apply patches. This page doesn't hand out patched clients.
  4. Download the connection files and put both in the client's data folder, next to the .exe (make the folder if it isn't there). Replace any copies already in it.{{if eq .PacketVer "20250716"}} WARPGATE leaves these files alone when it updates the client.{{end}}

    clientinfo.xml sclientinfo.xml

    They're the same file under the two names clients look for. If the patcher asked you for a custom file name, rename one of them to that.
  5. Start the patched client and log in with your account. If it can't connect, check that this PC can reach {{.Address}} and that the server's firewall lets the ports above through.

If the server's address changes, for example after its PC gets a new address from the router, download the files again.
