Steps

These steps are for Windows.

  1. Make an account. {{if $.Account}}You're logged in as {{$.Account.UserID}}, so this is done.{{else}}Create one here; the game uses the same username and password.{{end}}
  2. Install the Korean client. Get it with WARPGATE: create a gate (a folder for the client) and let it download the client. You don't need WARPGATE's RAGEXE or WARP tabs; the patcher below brings the client exe this server uses.
  3. Install the English translation. In WARPGATE, open the LANG tab, choose {{.Mode}} and install it. That's llchrisll's English translation, and WARPGATE keeps it up to date. The client exe from the patcher already reads it.
  4. Download the patcher and extract everything in it into the client folder, the one with data.grf in it. It holds the patcher, its settings, and the connection file for the data folder; let it replace any copies already there.

    Download the patcher

    If Windows says it protected your PC when you start the patcher, click More info, then Run anyway. It warns about any program that isn't signed by a known company.
  5. Start {{.PatcherExe}} in the client folder. It downloads this server's client and its custom files, then says it's ready; click Play and log in with your account. Start the game from the patcher every time, so you always have the server's newest files. If it can't connect, check that this PC can reach {{.Address}} and that the server's firewall lets the ports above through.

If the server's address changes, for example after its PC gets a new address from the router, download the patcher again, or just the connection file for the data folder: clientinfo.xml.
