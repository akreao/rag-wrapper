Steps

These steps are for Windows.

  1. Make an account. {{if $.Account}}You're logged in as {{$.Account.UserID}}, so this is done.{{else}}Create one here; the game uses the same username and password.{{end}}
  2. Install the Korean client. Get it with WARPGATE: create a gate (a folder for the client) and let it download the client. You don't need WARPGATE's RAGEXE or WARP tabs; the patcher below brings the client exe this server uses.
  3. Install the English translation. In WARPGATE, open the LANG tab, choose {{.Mode}} and install it. That's llchrisll's English translation, and WARPGATE keeps it up to date. If the server switches between Pre-Renewal and Renewal, the mode above changes too; install the matching translation from the same tab. The client exe from the patcher already reads it.
  4. Download the patcher and extract everything in it into the client folder, the one with data.grf in it. It holds the patcher, its settings, and the connection files for the data folder; let it replace any copies already there, including the translation's ExternalSettings_kr.lub, which points the client's saved hotkeys and guild emblems at this server.

Start the game from the patcher every time, so you always have the server's newest files. If it can't connect, check that this PC can reach {{.Address}} and that the server's firewall lets the ports above through.

Playing on Linux

The client is a Windows program, but it runs well on Linux with Wine and DXVK, which runs the client's DirectX 9 graphics on Vulkan. Use plain Wine rather than Proton: under Proton the client starts but its window never opens.

  1. Install Wine and winetricks from your distribution's packages. winetricks downloads DXVK and the fonts, so the first start needs internet. DXVK also needs a graphics driver with Vulkan; vulkaninfo --summary should list your graphics card.
  2. Download the launcher. It makes a Wine setup just for the game in ~/.local/share/rag-wrapper-wine, installs DXVK and Microsoft's core fonts into it the first time, and starts the game from the client folder.

    {{.LinuxLauncher}}

    3. {{if and (eq .PacketVer "20250716") .Patcher.Available .Patcher.Patches}}
  3. Follow the steps above, starting each Windows program with the launcher: bash {{.LinuxLauncher}} run WARPGATE.exe. If WARPGATE won't run under Wine, copy a client folder it made on a Windows PC instead.{{if .Patcher.NewAvailable}} Download the new patcher rather than the main one; it's the one that has been checked under Wine.{{end}} Then put {{.LinuxLauncher}} in the client folder, next to data.grf.
    4. {{else}}
  4. Follow the steps above to get and patch a client, starting each Windows program with the launcher: bash {{.LinuxLauncher}} run program.exe. Then put {{.LinuxLauncher}} in the client folder, next to data.grf.
    5. {{end}}
  5. Choose DirectX 9. The first time you play from a client folder, the launcher opens OpenSetup before the game. In it, set the renderer to DirectX 9, pick your graphics card and resolution, and turn on Trilinear, which costs nothing with DXVK. If full screen stutters or switching windows misbehaves, play in a window instead. Save even if your choices are already there: the client remembers the graphics card as the Wine setup it last ran in saw it, and in a different one it runs without ever showing its window. To change these later, run bash {{.LinuxLauncher}} setup. If the DirectX 9 lists are empty, DirectX 9 isn't working under Wine; see the note below.
    6. {{if and (eq .PacketVer "20250716") .Patcher.Available .Patcher.Patches}}
  6. Play with bash {{.LinuxLauncher}} in the client folder. It starts the patcher, and the patcher's Play starts the game.
    7. {{else}}
  7. Play with bash {{.LinuxLauncher}} run and the name of your patched client's .exe.
    8. {{end}}

The launcher caps the game at 60 frames a second, which stops it keeping a processor core busy. To change the cap, edit d3d9.maxFrameRate in ~/.config/dxvk-ro.conf. If the game won't start after DXVK is installed, your graphics driver may be too old for the newest DXVK; run WINEPREFIX=~/.local/share/rag-wrapper-wine winetricks dxvk1103 to install an older one. Without Vulkan at all, start the launcher with RO_DXVK=0 in front, which uses Wine's own, slower DirectX. If installing the fonts fails, the game still starts and the launcher tries again next time; to stop it trying, start the launcher with RO_FONTS=0 in front.
